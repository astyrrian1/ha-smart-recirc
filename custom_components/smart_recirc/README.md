# Smart Recirc 0.4.0

Experimental local integration with 23 entities, including an optional calibrated gallons-per-minute flow sensor, settings controls, guarded pump actions, controller schedules and bounded logs. Firmware 6.2.2 and HA 2026.9.2 are the validated target. See the repository parity matrix and flow calibration guide for limitations.

Install the ZIP generated by `tools/build_integration.py`; it includes the library. Updates arrive over a persistent push connection, with no periodic polling. Connections may re-enable smart timers. Protected controllers, provisioning and firmware updates remain unsupported.
